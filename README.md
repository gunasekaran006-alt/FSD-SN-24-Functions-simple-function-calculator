# Simple Function-Based Calculator

This is a basic JavaScript project created to practice the fundamental concepts of **Functions**, **Parameters**, and **Return Statements**.

## 🚀 Features
- **Modular Code:** Each arithmetic operation is handled by a dedicated function.
- **Dynamic Inputs:** Functions accept parameters for flexibility.
- **Return Values:** Results are calculated and returned to be displayed or used elsewhere.

## 🛠️ Operations Included
1. **Addition (`add`)**: Returns the sum of two numbers.
2. **Subtraction (`subtract`)**: Returns the difference between two numbers.
3. **Multiplication (`multiply`)**: Returns the product of two numbers.
4. **Division (`divide`)**: Returns the quotient and handles division-by-zero errors.

## 📝 How to Run
Simply copy the code into your browser's console or run it using Node.js:
```bash
node calculator.js
